## What this repo is

A GitHub Pages–hosted Kodi add-on repository served at `https://tony7bones.github.io/repo`. Kodi points at this URL to discover and install add-ons. The site is purely static — no build system, no Node, no bundler.

## Commands

```bash
# Regenerate addons.xml, addons.xml.sha256, per-addon zips, and index pages
python3 _tools/generate_repo.py

# Lint the Python tooling
ruff check _tools/
```

## Architecture

### Two distinct content areas under `repo/`

| Path                 | Purpose                                                                                                                                        |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `repo/`              | Kodi plugin add-ons. Each subdirectory with an `addon.xml` becomes a zip and is listed in `addons.xml`.                                        |
| `repo/repositories/` | Stand-alone repository installer zips (e.g. `repository.bugatsinho-2.8.zip`). These are **not** in `addons.xml` — Kodi installs them manually. |
| `repo/media/`        | Images browsable from Kodi's file manager. `index.html` is auto-generated by CI.                                                               |

### Generator — `_tools/generate_repo.py`

Driven by `process_addons()` which scans a directory for subdirs containing `addon.xml`:

1. Zips the addon directory → `{id}-{version}.zip` (skips `.zip` and `.html` files)
2. Writes a per-addon `index.html`
3. Aggregates all addon XML roots into `repo/addons.xml` + `repo/addons.xml.sha256`
4. Writes a styled `repo/repositories/index.html` listing all `.zip` files

**`repo/index.html` is hand-crafted and never touched by the generator** (explicit comment in the script). Edit it directly.

### CI — `.github/workflows/generate_repo.yml`

Triggers on push to:

- `repo/**/addon.xml` — runs `generate_repo.py` then commits generated artifacts
- `repo/media/**` — regenerates `repo/media/index.html` from image files present (inline Python step)

The workflow commits back with `github-actions[bot]` and pushes to `main`. After pushing a new image to `repo/media/`, CI auto-updates the index — no manual edit needed.

### Adding a new Kodi add-on

1. Create `repo/<addon-id>/addon.xml` following the Kodi addon.xml schema
2. Push — CI runs `generate_repo.py`, produces the zip and updates `addons.xml`

### Adding a new repository installer zip

1. Drop the `.zip` into `repo/repositories/`
2. Push — CI regenerates `repo/repositories/index.html`

### Kodi source URL

`https://tony7bones.github.io/repo` — already configured in `_tools/repo-sources/repository.tony7bones/addon.xml`
